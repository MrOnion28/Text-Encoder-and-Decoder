# Text Encoder and Decoder

If you have ever completed a cipher challenge, you would know the pain of checking various solutions or trying to find answers through long, monotonous repetition. Well, our Text Encoder and Decoder fixes just that!

# What we did
We created a text encoder and decoder that converts text into ciphertext based on various different cipher types, and also decrypts ciphertext for these cipher types. Our code encrypts plaintext through a Caesar cipher, Substitution cipher, Morse code, Vigenere cipher, Affine cipher, Hill cipher and Columnar transposition cipher. It decrypts the first 5. 

# The Structure

We separated the code into functions for encryption, functions for decryption, encryption inputs, and the decryption inputs.
