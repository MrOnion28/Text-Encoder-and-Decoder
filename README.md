We created a text encoder and decoder that converts text into ciphertext based on various different cipher types, and also decrypts ciphertext for these cipher types. Our code encrypts plaintext through a Caesar cipher, substitution cipher, morse code, vigenere cipher, affine cipher, hill cipher and columnar transposition cipher. It decrypts the first 5. We separated the code into functions for encryption, functions for decryption, encryption inputs, and the decryption inputs. We made this code project because we wanted an easier way to find solutions or test answers for cipher challenges.
